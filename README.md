# 🎮 Pixel Forge Studios

## Nome do Projeto

**Pixel Forge Studios**

---

## Objetivo

Desenvolver um site institucional para uma empresa fictícia de desenvolvimento de jogos digitais, apresentando seus principais títulos, informações sobre a empresa, uma área de comunidade e um formulário de contato. O projeto também tem como objetivo aplicar conceitos de desenvolvimento web front-end, responsividade e interatividade utilizando HTML, CSS e JavaScript.

---

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Local Storage (armazenamento da preferência de tema)
* Flexbox
* CSS Grid
* Media Queries

---

## Estrutura de Pastas

```text
pixelForgeStudios/
│
├── assets/
│   ├── fonts/
│   └── img/
│
├── index.html
├── comunity.html
├── styles.css
├── script.js
└── README.md
```

### Descrição

* **assets/fonts/** → Fontes utilizadas no projeto.
* **assets/img/** → Imagens, banners, logos, ícones e cards dos jogos.
* **index.html** → Página principal do site.
* **comunity.html** → Página da comunidade.
* **styles.css** → Arquivo responsável pela estilização da aplicação.
* **script.js** → Arquivo responsável pelas funcionalidades em JavaScript.
* **README.md** → Documentação do projeto.

---

## Como Executar o Projeto

1. Faça o download ou clone o repositório:

```bash
git clone https://github.com/Risqueira/pixelForgeStudios.git
```

2. Abra a pasta do projeto.

3. Execute o arquivo:

```text
index.html
```

4. O projeto será aberto no navegador padrão.
